**Tag** — uppercase mono chip for verticals, categories, statuses and metadata.

```jsx
import { Tag } from './Tag';

<Tag variant="soft">Community</Tag>
<Tag variant="solid" tone="sun">Live</Tag>
<Tag variant="outline" tone="sky">Workshop</Tag>
```

Variants: `soft` (tinted), `solid` (filled, dark text), `outline` (hairline). `tone` picks the brand pop colour.
